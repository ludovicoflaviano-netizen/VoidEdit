# VoidEdit

Modern desktop video editor focused on a fast timeline and simple controls.

## Prototype features
- Electron desktop shell
- React and Vite interface
- Media import dialog
- Media bin and clip selection
- Multi-track video and audio timeline
- Preview and transport controls
- Inspector controls for scale, opacity, and speed
- Text, effects, transitions, filters, and audio sections
- Responsive editor layout

## Run
npm install
npm run dev
